# Linko — สรุปความคืบหน้าโปรเจกต์ Social Network

> **เทคโนโลยี:** Flutter / Dart / Firebase Authentication / Cloud Firestore / Firebase Storage  


## 1. สถานะตามข้อกำหนดอาจารย์ทั้ง 10 ข้อ

| ข้อ | ระบบ | สถานะ | รายละเอียด |
|---|---|---|---|
| 1 | ระบบสมาชิก | ⟳ กำลังพัฒนา | สมัครสมาชิก / Login / Logout มีโค้ด; Edit Profile และ Forgot Password ยังไม่ทำ |
| 2 | ระบบโพสต์ | ✅ เสร็จแล้ว | มี CRUD โพสต์ พร้อมข้อความ รูปภาพ วิดีโอ และแท็ก; ทดสอบการใช้งานจริงต่อ |
| 3 | Feed / Timeline | ✅ เสร็จแล้ว | แสดงฟีดเรียงตามเวลา (ใหม่ก่อน); รอทดสอบกับข้อมูลจริงต่อ |
| 4 | Like / Dislike / Emoji / Comment | ⟳ กำลังพัฒนา | Comment มีเพิ่ม/อ่านและแจ้งเตือน; Like, Dislike และ Emoji Reaction ยังไม่ทำ |
| 5 | Chat 1-1 | ⟳ กำลังพัฒนา | มี Chat List / Chat Room และข้อความ รูปภาพ วิดีโอ; รอทดสอบครบด้วยสองบัญชี/สอง Emulator |
| 6 | Groups / Pages | ❌ ยังไม่ทำ | ยังไม่มีระบบสร้าง เข้าร่วม แก้ไข ออก ลบกลุ่ม/เพจ และ Group Feed |
| 7 | Profile / Follow / Search | ⟳ กำลังพัฒนา | มีค้นหาผู้ใช้เบื้องต้น; Profile, Public/Private และ Follow/Unfollow ยังไม่ครบ |
| 8 | Report Post | ⟳ กำลังพัฒนา | มีหน้าหรือ Dialog และโค้ดบันทึก `post_reports`; รอทดสอบจริง |
| 9 | ฟีเจอร์ตาม Pain Point ผู้ใช้จริง | ❌ ยังไม่ทำ | ยังไม่มีหลักฐานการเก็บ Pain Point และฟีเจอร์ที่พัฒนาเพื่อตอบโจทย์นั้น |
| 10 | Cloud Database | ⟳ กำลังพัฒนา | เชื่อม Firebase และ Deploy Rules / Indexes แล้ว; ยังต้องทดสอบสิทธิ์และ Query กับระบบจริง |

**สัญลักษณ์สถานะ:** 
✅ เสร็จแล้ว • ⟳ กำลังพัฒนา / รอตรวจสอบ • ❌ ยังไม่ทำ

## 3. สิ่งที่พัฒนาแล้ว (มีโค้ดหรือหน้าจอ)

### 3.1 ระบบบัญชีและ UI
- สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ ด้วย Firebase Authentication
- มีข้อมูลสมาชิกใน Firestore (`users`)
- ธีม Dark Mode / Light Mode และ UI ของ Linko
- Bottom Navigation หลัก 5 เมนู: หน้าหลัก, กลุ่ม, แชท, แจ้งเตือน, โปรไฟล์

### 3.2 ระบบโพสต์และฟีด
- Create / Read / Update / Delete โพสต์
- รองรับข้อความ, รูปภาพ, วิดีโอสั้น และ Hashtag
- มีฟีดเรียงจากโพสต์ล่าสุดไปเก่าสุด
- มีโค้ดสำหรับการมองเห็นโพสต์และจัดการสิทธิ์บางส่วน ซึ่งต้องตรวจ Security Rules ประกอบ

### 3.3 ฟีเจอร์ที่มีโค้ดใน Week 4
- Chat List และ Chat Room แบบ 1-1
- ส่งข้อความ และแนบรูปภาพ/วิดีโอในแชท
- ตัวนับข้อความที่ยังไม่อ่านแสดงในเมนูแชท; เมื่อเปิดห้องจะบันทึกสถานะอ่านแล้ว
- In-app Notification สำหรับ Comment; ออกแบบให้แจ้งเตือนทางสังคมอยู่ในหน้านี้ ส่วนแชทใช้ตัวนับในเมนูแชท
- Search / Explore สำหรับผู้ใช้, โพสต์ และ Hashtag
- ฟอร์มรายงานโพสต์และการส่งข้อมูลรายงาน
- เพิ่ม/อ่าน Comment และสร้าง Notification ที่ตรวจเทียบกับเอกสาร Comment ใน Firestore Rules

**ยังไม่นับว่าเสร็จสมบูรณ์จนกว่าจะทดสอบระบบจริงผ่าน**

## 4. สิ่งที่ยังไม่เสร็จหรือยังไม่มีระบบจริง

### 4.1 ฟีเจอร์หลักที่โจทย์บังคับ
- ❌ Like โพสต์ พร้อมบันทึกและแสดงสถานะจาก Firestore
- ❌ Dislike โพสต์ พร้อมบันทึกและแสดงสถานะจาก Firestore
- ❌ Emoji Reactions อื่น ๆ
- ⟳ Comments: มีเพิ่ม/อ่านและแจ้งเตือนเจ้าของโพสต์; ต้องทดสอบสิทธิ์และกรณีขอบเพิ่มเติม
- ❌ Groups / Pages: สร้าง / เข้าร่วม / แก้ไข / ออก / ลบ
- ❌ Group Feed: โพสต์และปฏิกิริยาเหมือน Feed หลัก
- ⟳ Profile: มีข้อมูลสมาชิกพื้นฐาน; หน้าดูโปรไฟล์ยังไม่ครบ
- ❌ Edit Profile: แก้ไขข้อมูลและรูปโปรไฟล์
- ❌ Follow / Unfollow และรายชื่อ Followers / Following
- ⟳ โปรไฟล์ Public / Private: มีฟิลด์ `isPrivate` แต่การแยกข้อมูลและควบคุมสิทธิ์ยังไม่ครบ
- ❌ ฟีเจอร์เพิ่มเติมจาก Pain Point ของผู้ใช้จริง

### 4.2 ฟีเจอร์เสริมและจุดที่ควรปรับปรุง
- ❌ Forgot Password เชื่อม Firebase Auth ให้ส่งอีเมลรีเซ็ตรหัสผ่านได้
- ⟳ Search รองรับข้อมูลจำนวนมากกว่าแนวทางดึงผู้ใช้ล่าสุด 150 ราย / โพสต์สาธารณะล่าสุด 80 ราย
- ❌ เพิ่มระบบจัดการรายงานโพสต์สำหรับผู้ดูแล (แนะนำ; ไม่ได้ระบุว่าเป็นหน้าบังคับแยกต่างหาก)
- ⟳ ตรวจและปรับความเร็วการโหลดรูปจาก Firebase Storage
- ⟳ ตรวจ UX ระหว่างอัปโหลดรูปภาพ/วิดีโอ โดยแสดงสถานะระหว่างรอ

**Push Notification:** ยังไม่มี แต่โจทย์ Week 4 อนุญาตให้ใช้ *In-app หรือ Push* จึงไม่จำเป็นต้องทำ Push หาก In-app ทำงานครบแล้ว

## 5. ความปลอดภัยและงานที่ต้องตรวจสอบก่อนปิด Week 4

### 5.1 จุดที่ควรปรับปรุงด้านความปลอดภัย

| สถานะ | ประเด็น | สิ่งที่พบ / งานที่ต้องทำ |
|---|---|---|
| ⟳ | สิทธิ์อ่าน `users` | ผู้ใช้ที่ล็อกอินอ่านเอกสารผู้ใช้ทุกคนได้ ซึ่งรวม `isPrivate` และข้อมูลค้นหา ควรแยกข้อมูลสาธารณะออกจากข้อมูลส่วนตัวก่อนปรับ Rules; ปัจจุบันเอกสารสมัครสมาชิกไม่มีอีเมล |
| ⟳ | ฟิลด์สรุปแชท | สมาชิกห้องแก้ `unreadCounts` และข้อมูลข้อความล่าสุดได้ ควรจำกัดการเปลี่ยนค่าตาม UID และตรวจให้สอดคล้องกับข้อความที่ส่ง |
| ✅ | ข้อมูลผู้ส่ง Notification ของ Comment | Rules ตรวจ actor และเนื้อหากับ Comment ที่สร้างในคำขอเดียวกัน; Rules ยังไม่อนุญาตให้ Client สร้างการแจ้งเตือน Like/Follow |
| ❌ | Firebase App Check | ยังไม่พบการเพิ่ม SDK หรือการตั้งค่า App Check |
| ❌ | Forgot Password | หน้าจอยังไม่เชื่อม Firebase Auth เพื่อส่งอีเมลรีเซ็ตรหัสผ่าน |
| ✅ | Deploy Firestore Rules / Indexes | ผู้ใช้ยืนยัน Deploy `firestore:rules` และ `firestore:indexes` สำเร็จไปยัง `social-network-app-c22eb`; ควรทดสอบสิทธิ์กับบัญชีจริงสองบัญชี |

### 5.2 งานที่ต้องตรวจสอบก่อนปิด Week 4

| สถานะ | งาน | สิ่งที่ต้องตรวจสอบ |
|---|---|---|
| ⟳ | Firestore Rules | Deploy แล้ว; ทดสอบสิทธิ์อ่าน/เขียนกับบัญชีจริงสองบัญชี |
| ⟳ | Firestore Indexes | Deploy แล้ว; ตรวจว่า Query ของ Chat / Notifications / Search ทำงานครบ |
| ⟳ | Firebase Storage Rules | ตรวจสิทธิ์อ่าน/เขียนรูปภาพและวิดีโอของผู้ใช้แต่ละคน |
| ⟳ | Chat Text | ใช้ผู้ใช้ 2 บัญชีทดสอบการส่งและรับข้อความแบบ Real-time |
| ⟳ | Chat Media | ส่งรูปภาพ/วิดีโอ เปิดดูไฟล์และจัดการข้อผิดพลาดได้จริง |
| ⟳ | Notifications | ทดสอบ Comment Notification, ตัวนับแชท และสถานะอ่านแล้ว/ยังไม่อ่าน |
| ⟳ | Search | ค้นหาผู้ใช้ โพสต์ Hashtag และกรองข้อมูลด้วยข้อมูลจริง |
| ⟳ | Performance | ทดสอบซ้ำกรณีโหลดรูปช้า และรออัปโหลดไฟล์นาน |
