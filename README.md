# Linko

Linko เป็นแอปโซเชียลเน็ตเวิร์กที่พัฒนาด้วย Flutter และ Firebase ข้อมูลด้านล่างสรุปจากโค้ดเวอร์ชัน `1.1.5+9`

## ฟังก์ชันของแอป

1. **บัญชีผู้ใช้** — สมัครและเข้าสู่ระบบด้วยอีเมล ยืนยันอีเมล รีเซ็ตรหัสผ่าน และออกจากระบบ ฟอร์มบนมือถือเลื่อนได้เมื่อแป้นพิมพ์เปิดหรือพื้นที่หน้าจอไม่พอ
2. **โปรไฟล์** — แก้ชื่อ Bio รูปโปรไฟล์และรูปปก ดูโพสต์ของตัวเอง รวมถึงตั้งบัญชีสาธารณะหรือส่วนตัว
3. **ติดตามผู้ใช้** — ติดตามหรือเลิกติดตาม ดูรายชื่อผู้ติดตาม และส่งหรือจัดการคำขอติดตามบัญชีส่วนตัว
4. **ฟีดและโพสต์** — สร้าง แก้ไข และลบโพสต์ข้อความ รูปภาพหรือวิดีโอ ใส่แฮชแท็ก แท็กเพื่อน และเลือกสิทธิ์การมองเห็น
5. **ปฏิสัมพันธ์กับโพสต์** — แสดงความคิดเห็น กดถูกใจ ไม่ถูกใจ หรืออิโมจิอื่น และเปิดดูว่าใครกดอิโมจิอะไร
6. **กลุ่ม** — กลุ่มสาธารณะอ่านโพสต์และดูสื่อได้ก่อนเข้าร่วม ต้องเข้าร่วมจึงโพสต์/แสดงความคิดเห็น/กดความรู้สึกได้ ส่วนกลุ่มส่วนตัวต้องรออนุมัติก่อนอ่าน รองรับรูปกลุ่มและการจัดการสมาชิก
7. **แชทส่วนตัว** — ส่งข้อความและสื่อ ดูข้อความที่ยังไม่อ่าน ยกเลิกข้อความ และลบประวัติแชทเฉพาะบัญชีตัวเอง
8. **แชร์โพสต์** — แชร์โพสต์สาธารณะไปฟีดตัวเอง กลุ่ม หรือแชท
9. **ค้นหา** — ค้นหาผู้ใช้ โพสต์ และแท็ก
10. **แจ้งเตือนในแอป** — ดูรายการแจ้งเตือน จำนวนที่ยังไม่อ่าน และคำเตือนเรื่องสิทธิ์โพสต์
11. **รายงานและจัดการเนื้อหา** — รายงานโพสต์ เจ้าของกลุ่มจัดการรายงานในกลุ่ม และระบบเตือนหรือพักสิทธิ์โพสต์ตามกติกา
12. **บล็อกผู้ใช้** — บล็อกหรือปลดบล็อก และดูรายชื่อผู้ใช้ที่บล็อก
13. **การแสดงผล** — เลือกโหมดสว่างหรือมืดและสีหลักของแอป

## สิทธิ์โปรไฟล์และโพสต์

โปรไฟล์ส่วนตัวต้องอนุมัติผู้ติดตามก่อนจึงเห็นโพสต์ที่เลือก **สาธารณะ** ส่วนโพสต์ **เฉพาะฉัน** เห็นได้เฉพาะเจ้าของ ไม่เปลี่ยนตามการเปิดหรือปิดโปรไฟล์ ผู้ที่ยังรออนุมัติหรือยกเลิกการติดตามแล้วไม่มีสิทธิ์ดูโพสต์ของบัญชีส่วนตัว กติกานี้ใช้ทั้งฟีด หน้าโปรไฟล์ และไฟล์รูป/วิดีโอ หน้าสร้าง/แก้ไขโพสต์แสดงชื่อ **สาธารณะ** และไม่แสดงคำอธิบายโปรไฟล์ใต้ตัวเลือกนี้

รายละเอียดเมทริกซ์สิทธิ์ ไฟล์ที่เกี่ยวข้อง และการทดสอบอยู่ใน [คู่มือความเป็นส่วนตัวของโพสต์](tool/POST_PRIVACY.md)

แก้รูปโพสต์โหลดไม่ได้วันที่ 4 พ.ย. 2026: ไฟล์ JPEG ยังอยู่ แต่ Storage Rules เรียก Firestore เกินขีดจำกัดในเส้นทางผู้ชมทั่วไป ปรับลำดับเงื่อนไขและเผยแพร่เฉพาะ Storage Rules แล้ว ทดสอบ Emulator ผ่าน 118 เงื่อนไข และโหลดรูปเดิมจาก Firebase จริงได้ HTTP 200 ครบ 169,182 ไบต์ อ่าน Rules กลับมาตรงกับไฟล์ที่ทดสอบ ดู [ผลตรวจและรายละเอียดการแก้](docs/feed-media-rules-fix-2026-11-04.md)



## รายงานซ้ำและพักโพสต์ 72 ชั่วโมง

เปิดใช้บน Firebase แล้ววันที่ 4 พ.ย. 2026: เคสแรกเตือนให้แก้ตามเดิม เคสใหม่ที่ถึงเกณฑ์ภายใน 90 วันพักโพสต์ 72 ชั่วโมง การแก้โพสต์ไม่ล้างประวัติ และการส่งซ้ำไม่เพิ่มจำนวนเคส มีเพียงสองระดับ ไม่เพิ่มโทษ 7/30 วัน เริ่มสะสมจากเคสที่ถึงเกณฑ์หลังเปิดใช้ ไม่ดึงรายงานเก่ามาลงโทษย้อนหลัง Unit Test ผ่าน 40 กรณี และ integration ผ่าน 48 กรณี รายละเอียดขอบเขต การเปิดใช้ และการทดสอบอยู่ใน [คู่มือพักโพสต์จากรายงานซ้ำ](docs/repeat-report-suspension.md)

## อ่านกลุ่มสาธารณะโดยไม่เข้าร่วม

แยกสิทธิ์อ่านออกจากการเป็นสมาชิก ทั้งหน้าแอป Firestore และ Storage กลุ่มส่วนตัวคงตรวจสมาชิกที่อนุมัติแล้ว การโหลดสื่อใช้ `groupVisibility` ที่ผ่านการตรวจสอบกับกลุ่มจริง เพื่อไม่ให้ Storage เรียก Firestore เกินขีดจำกัด รายละเอียดไฟล์ที่แก้ การเติมค่าให้โพสต์เก่า และการทดสอบอยู่ใน [คู่มือกลุ่มสาธารณะ](docs/public-group-reading-2026-11-04.md)

เผยแพร่ Firebase จริงแล้ววันที่ 4 พ.ย. 2026 และเติมประเภทกลุ่มครบ 7 โพสต์โดยคงเนื้อหา เวลาโพสต์ และสื่อเดิม ทดสอบบัญชีที่ไม่ได้เข้ากลุ่มแล้วอ่านโพสต์สาธารณะทั้ง 5 โพสต์ รวมวิดีโอ/รูปตัวอย่างได้ HTTP 200 ขณะที่กลุ่มส่วนตัวยังคงปฏิเสธ HTTP 403 การเปลี่ยนหน้ากลุ่มต้องติดตั้งแอปรุ่นใหม่ด้วย

## การตรวจฟอร์มบนมือถือ

แก้แถบเหลือง `BOTTOM OVERFLOWED` โดยให้ [หน้าเข้าสู่ระบบ/สมัครสมาชิก](lib/screens/login/login.dart) ใช้พื้นที่เลื่อนได้เสมอ แทนการตรวจแป้นพิมพ์จาก `viewInsets` ภายใน body ที่ Scaffold ย่อพื้นที่และล้าง inset ไปแล้ว โครงสร้าง Form คงเดิมเมื่อแป้นพิมพ์เปิด/ปิด จึงเก็บข้อมูลร่างและข้อความตรวจฟอร์มไว้ได้

ชุด [ทดสอบ layout](test/registration_layout_test.dart) และ [ทดสอบฟอร์มเดิม](test/widget_test.dart) ผ่าน 11/11 กรณี ครอบคลุมจอ 320×640 และ 393×852 ทั้งสว่าง/มืด แป้นพิมพ์สูง 300 พิกเซล จอแนวนอนพร้อมตัวอักษร 1.4 เท่า การเลื่อนไปกรอกครบทุกช่องและกดปุ่ม รวมการปิด/เปิดแป้นพิมพ์ซ้ำ Analyzer ของสองไฟล์ที่แก้ไม่พบปัญหา ผลนี้เป็น Widget Test จำลองพื้นที่หน้าจอ ยังไม่ได้ติดตั้งตรวจบนโทรศัพท์จริง

รันซ้ำด้วย `flutter test --no-pub test/registration_layout_test.dart test/widget_test.dart` หากใช้งานผ่าน APK ที่ติดตั้งไว้ ต้องสร้างและติดตั้ง APK จากโค้ดใหม่จึงจะได้รับการแก้ไข

## APK สำหรับติดตั้งทดสอบ

APK ล่าสุดในเครื่องคือ `build/app/outputs/flutter-apk/Linko-1.1.5-build9-debug.apk` รุ่น **1.1.5 (build 9)** ขนาดประมาณ 158.7 MiB เป็น Debug APK จาก `lib/main.dart` รองรับ `armeabi-v7a`, `arm64-v8a` และ `x86_64` เปลี่ยนชื่อผู้ชมโพสต์เป็น **สาธารณะ** และเอาคำอธิบายโปรไฟล์ใต้ตัวเลือกนี้ออก รวมการอ่านกลุ่มสาธารณะก่อนเข้าร่วมและการแก้ฟอร์มสมัครสมาชิกล้นจอจากรุ่นก่อนแล้ว

ตรวจ manifest ลายเซ็น และข้อความหน้าสร้างโพสต์ใน kernel ของ APK แล้ว พบข้อความใหม่และไม่มีชื่อ/คำอธิบายเดิม ลายเซ็นตรงกับรุ่น 1.1.4 (build 8) จึงใช้ติดตั้งอัปเดตทับรุ่นเดิมที่เซ็นด้วยคีย์เดียวกันได้ ชุดทดสอบฟอร์มผ่าน 12 กรณี และ Analyzer ไม่พบปัญหา ผล build/แฮชไฟล์/รายละเอียดตรวจสอบรุ่นใหม่อยู่ใน `build/apk-audience-label/` เก็บ APK รุ่นก่อนหน้าไว้แล้ว ยังไม่ได้ติดตั้งทดสอบบนโทรศัพท์จริง

## เทคโนโลยีที่ใช้

1. **Flutter และ Dart** — พัฒนาแอปและหน้าจอ
2. **Material 3** — ระบบธีมและองค์ประกอบ UI
3. **Firebase Authentication** — บัญชีผู้ใช้และการยืนยันอีเมล
4. **Cloud Firestore** — เก็บโปรไฟล์ โพสต์ กลุ่ม แชท และข้อมูลอื่นของระบบ
5. **Firebase Storage** — เก็บรูปภาพและวิดีโอ
6. **Cloud Functions Gen 2 บน Node.js 22 และ Firebase Admin SDK** — ตรวจสิทธิ์และทำงานฝั่งเซิร์ฟเวอร์ เช่น รายงาน แชร์ และพักสิทธิ์โพสต์
7. **Cloud Scheduler** — เรียกงานตรวจคำเตือนและงานเบื้องหลังตามเวลา
8. **Firestore Rules และ Storage Rules** — กำหนดสิทธิ์อ่านและเขียนข้อมูล
9. **SharedPreferences** — จำการตั้งค่าในเครื่อง เช่น ธีม
10. **image_picker, video_player และ video_thumbnail** — เลือก แสดง และสร้างภาพตัวอย่างของสื่อ
11. **Firebase Emulator, Flutter Test และ Node.js Test** — เครื่องมือทดสอบระบบ
